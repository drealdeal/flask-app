# Super Mario Game for iPhone

A fun HTML5 Canvas-based Mario platformer game optimized for iPhone with touch controls!

## Quick Start - Play on iPhone

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Run the game:
   ```bash
   python yt_scraper.py
   ```

3. Look for the ngrok URL in the terminal output:
   ```
   🎮 SUPER MARIO GAME - READY TO PLAY!
   📱 Open this URL on your iPhone:
      https://xxxx-xx-xx-xx-xx.ngrok-free.app
   ```

4. Open that URL on your iPhone and start playing!

## Game Features

- Classic Mario-style platformer
- Touch controls optimized for mobile
- Collect coins for points
- Avoid enemies
- Multiple platforms to jump on
- Lives and score tracking

## Controls

- **◀** Left button - Move left
- **▶** Right button - Move right
- **↑** Jump button - Jump

## How to Play

- Navigate through platforms by moving left and right
- Jump to reach higher platforms and collect coins
- Avoid the enemy creatures
- Try to get the highest score!

## Tech Stack

- Flask (Python web framework)
- HTML5 Canvas for game rendering
- JavaScript for game logic
- ngrok for public URL tunneling
- Touch-optimized controls for mobile devices
